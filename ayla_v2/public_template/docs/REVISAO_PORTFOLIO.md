# Revisão antes de candidatar

Explique sem decorar: a diferença entre construir a aplicação e treinar o modelo; como a busca
é formulada; como as fontes são rastreadas; o que o modelo pode pedir versus o que o backend
permite; por que uma página não autoriza mutações; como o cálculo é executado sem eval; limitações
do contexto curto, das fontes e da qualidade de um modelo de 4B; como invalidar uma chave vazada.

Medidas a coletar: taxa de chamadas corretas, respostas sustentadas pelas fontes, erros,
latência medida por pergunta e limitações. Não confundir esses dados com testes determinísticos
ou com resultado empresarial. Avaliar com perguntas inéditas, não só exemplos do README.

Sugestão de demo: explicação geral, cálculo, pesquisa com fonte aberta, pergunta de continuação,
proposta de alteração que só é salva depois do clique. Ditado é opcional; testar o microfone real.
